description: Instalar, actualizar o conectar LOCO Detector con un agente local en Windows o Mac y verificar el resultado.
---

Sigue la [guía de instalación y actualización](../../../docs/INSTALAR_ACTUALIZAR.md). Identifica si se trata de escritorio, Docker o desarrollo. Para «actualiza LOCO» compara la versión instalada con la release estable del repositorio oficial. Conserva los proyectos y confirma al final la versión que responde y su proyecto activo. Una versión publicada solo para Docker no es una actualización del escritorio.
